# Part 1: Neural Network Fundamentals and Training Behavior Analysis

This repository contains an end-to-end implementation of a feed-forward neural network built to analyze and predict customer churn patterns using a supervised learning approach.

## Repository Layout
- `notebook.ipynb`: Contains full implementation steps covering exploration, preprocessing, model training, and hyperparameter tuning.
- `requirements.txt`: Python package dependency details.
- `results/`: Holds exported analytical graphs and experimental data comparison matrices.

## Key Insights
Our experimentation showed that deep architectures with conservative learning rates systematically outperform shallow architectures with high learning rates, which often fail to converge smoothly due to gradient overshooting.
